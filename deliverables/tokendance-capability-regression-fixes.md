# TokenDance 能力组合回归修复

## 修复范围

| 问题 | 修复位置与行为 |
|---|---|
| Seedream 分镜图片同时传尺寸和非法比例仍受理 | `StoryboardImageGenerationServiceImpl` 保留原始比例，统一模型规格解析后再预扣；其他供应商保持原尺寸优先语义 |
| 参考视频总时长超限被误报内部失败 | `ReferenceVideoCapabilityValidator` 在报价校验已知可信时长，正式提交校验完整元数据；返回稳定用户输入错误 |
| Wan3 合法参考视频报缺少时长 | 原厂适配不再抢先处理 TokenDance 同名模型；独立方言处理毫秒精度、单段／总长及输入输出合计 |
| Kling Omni 视频参考误入图片场景 | 公共场景解析按声明的允许模态选择视频场景，保留显式能力选择；协议继续校验音频、多镜头和主体组合 |
| MiMo 分镜配音吞掉参数错误 | 复用媒体报价预检，音频记录创建之前检查格式、采样率和音色 |
| Qwen3.7 Plus 视频开关与模态矛盾 | 模板先补显式模态开关再取协议交集；增量 SQL 修复已导入的已知矛盾配置 |
| 文本视频缺元数据被误判上下文过长 | 报价不以媒体占位 Token 触发实际上下文硬拒绝，仍估算完整费用；正式提交验证实际元数据和上下文 |
| OpenAI Seedream Lite 通用报价漏像素边界 | 仅该型号复用 Seedream 实际尺寸规则，不复用 Ark 请求体、不扩大其他 OpenAI 模型能力 |
| 视频不支持的输出格式被忽略 | `output_format` 从通用允许集合移到 Seedance 专属集合；其他协议显式传入即拒绝 |
| H3 Max 文生比例缺项 | 补齐已核验比例、默认比例及分场景素材角色；首帧／首尾帧仍不向上游传比例 |

Wan3 另补 file/link 参考透传、同义字段冲突、首尾帧互斥及 `prompt_extend` 依赖；清晰度未配置时按官方默认 1080P，规划报价保留智能时长计费上界，避免校验副本丢失计费参数。负余额展示修复继续保留。

## 数据与目录

- 已导入实例使用 `sql/unreleased/110-tokendance-capability-consistency.sql`；依赖 030 配置版本及 100 能力绑定表结构。脚本兼容旧模型能力和新能力／协议绑定，保留非目标供应商、未知扩展、现有自定义比例、费率、SKU、倍率和状态。
- 执行前备份涉及模型、能力、协议绑定。维护窗口执行后重启服务清除缓存；无需执行整份初始化 SQL。新安装使用 `sql/aid-init.sql`。
- 新目录包含资源模板修复和不可变目录包 `model-catalog/tokendance/tokendance-catalog-2026.09.10.2.json`，由 `latest.json` 的摘要和签名引用。旧不可变包不覆盖，禁入模型策略不变，应用版本不递增。
- 目录文件提交不等于目录已发布。公开目录仍需按 `model-catalog/README.md` 先发布包、核对摘要，再激活签名清单；本次不部署、不执行线上 SQL、不发布应用版本。

## 验证边界与回滚

本地使用既有 72 模型配置作为覆盖清单，检查能力模板和成本 SKU 编译，并对已报告失败组合执行协议、服务层报价／提交预检对照；素材元数据采用测试夹具，不发起上游收费生成。独立 MySQL 5.7 校验增量脚本首次执行、重复执行和自定义配置保留。测试代码、账号、原始请求响应和媒体文件不进入仓库。

这些检查不能代替部署后的真实账号端到端验收；上游余额不足仍不能证明成功结果和最终用量结算。部署后应使用同一组真实素材核验合法对照与单项非法变体，检查非法请求在预扣前被拒绝，以及任务失败退款和成功实际用量结算。

代码可回滚本次提交；目录清单切回之前已签名的可信清单，不覆盖不可变文件。配置回滚须从执行前备份按模型／绑定标识及当前配置版本受控恢复，不能用历史整表覆盖后续管理员修改。旧任务继续使用自身已冻结的路由和计费快照。

Web 未修改。若需要 UI 支持 Wan3 file/link，需提供互斥输入与提示词改写开关；错误展示继续读取服务端错误，不能把失败报价显示成零价。
