# 版本发布说明

## v1.0.0-beta.4

- 为官方风格、用户自定义风格和项目增加角色、场景、道具三类隐藏风格提示词，生成链路优先使用项目快照，避免后续修改导致同一项目风格漂移。
- 项目创建与更新统一保存风格来源、公开描述及隐藏描述快照；项目已有角色、场景或道具后锁定风格切换，继续允许保存其他生成配置。
- 后台管理增加隐藏风格提示词的分区编辑与只读快照展示，项目列表明确显示风格名称并保护快照字段不被普通编辑覆盖。
- Web 精选风格库支持官方与自定义风格合并分页、稳定来源标识、当前风格定位和锁定状态提示，修复历史项目风格识别及重复选择问题。
- 优化后台左上角版本信息面板的布局与点击交互，并修复登录后直接访问后台管理入口码路径时错误进入 404 的问题。
- 新增可重复执行的 `v1.0.0-beta.4.sql`：补齐隐藏风格字段与查询索引，仅同步开源初始化库现有的 51 个官方风格，不导入测试库的其他扩展数据。
- 初始化 SQL 已内置上述 51 个官方风格隐藏描述；移除重复的临时风格脚本和独立智能体教程初始化脚本，统一以 `sql/aid-init.sql` 为开源初始化真源。

## v1.0.0-beta.3

- 修复未识别错误日志中“基于此创建规则”进入错误页面的问题。
- 错误样本可直接打开规则编辑器，并自动带入厂商、模型、匹配类型和错误内容。
- 新增错误样本转规则接口，在同一事务中创建规则并回写样本处理结果。
- 新增规则命中校验和重复转换保护，避免无效规则或重复规则写入。
- 全局错误样本转换时自动恢复为全局规则范围，不再把 `_global` 当作厂商编码保存。
- 补齐错误样本转规则的菜单权限迁移，已有角色授权保持不变。
- 新增可重复执行的 `v1.0.0-beta.3.sql` 数据库迁移脚本。
- 项目升级页新增官方资源包初始化，可直接上传、校验并安全解压，同时提供下载入口和服务器命令兜底。
- 文件存储配置补充本地与云存储域名示例，明确本地模式仅官方 `/aid/...` 资源需要在公共域名中添加 `/profile`。
- 新增七牛云 Kodo 存储，支持动态配置、上传、删除、私有空间签名地址和读写删除连通性测试。
- 阿里云 OSS、腾讯云 COS 和本地存储的连通性测试升级为实际写入、校验、删除测试。
- 短信宝测试发送改用随机验证码，并明确接口成功仅表示通道受理；后台补充模板报备与重复内容拦截提示。
- 分集成片正式槽与待审槽增加独立素材指纹，并将旧库字段补齐和历史数据回填合并到测试 3 迁移脚本。

## v1.0.0-beta.2

- 重新设计后台基础配置页面，优化配置分组、视觉样式和操作体验。
- 新增会员协议、网站名称、网站描述和网站关键词配置，并通过公开配置接口返回。
- 网站关键词改为标签式编辑，保存时自动转换为英文逗号分隔内容。
- 交流二维码改为后台上传图片，不再要求管理员手工填写图片地址。
- 登录页 Logo 和后台左上角 Logo 合并为平台 LOGO，并与 Favicon 一起返回给 C 端。
- 删除基础配置中未使用的版本号配置，不影响独立的项目升级功能。
- 新增短信宝短信渠道，支持自定义签名、验证码内容、连接测试和测试短信发送。
- 短信验证码有效期、发送间隔和每日发送上限调整为后台可配置并由 Java 动态执行。
- 修复邮箱账号、发件人地址及同类文本编号字段被错误识别为数字输入框的问题。
- 完善短信宝验证码模板校验、响应解析和敏感日志保护。
- 统一后台用户身份判定并加固管理端上传失败处理。
- 修复平台品牌图片保存后未即时生效及清空页签图标后旧图标残留的问题。
- 邀请码改为发送登录验证码前预校验、首次注册时严格复核并自动绑定，删除独立预校验接口。
- 合并本次数据库更新为可重复执行的 `v1.0.0-beta.2.sql` 迁移脚本。

## v1.0.0-beta.1

- 发布 AID 首个公开 Beta 测试版本，面向自行部署和参与改进的开发者与创作者开放。
- 上线 AI 漫剧创作能力，覆盖创意、剧本、角色、场景、分镜、配音和成片流程。
- 上线 AI 电影项目化创作能力，支持叙事视频素材组织和生成任务编排。
- 上线 AI 漫画创作能力，支持角色、道具、场景、分镜和漫画画面统一管理。
- 建立图像、视频、语音和大语言模型的统一多模型接入能力。
- 建立生成任务统一调度、状态管理和计费处理链路。
- 上线用户、模型、供应商、系统配置、运营数据和版本升级管理后台。
- 提供初始化 SQL、Linux 部署脚本和 AID 升级器，支持项目部署与后续升级。
- 发布包含 608 个官方图片、音频试听和演示视频文件的配套资产包。
