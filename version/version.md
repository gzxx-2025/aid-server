# 版本发布说明

## v1.0.0-beta.2

- 重新设计后台基础配置页面，优化配置分组、视觉样式和操作体验。
- 新增会员协议、网站名称、网站描述和网站关键词配置，并通过公开配置接口返回。
- 网站关键词改为标签式编辑，保存时自动转换为英文逗号分隔内容。
- 交流二维码改为后台上传图片，不再要求管理员手工填写图片地址。
- 登录页 Logo 和后台左上角 Logo 合并为平台 LOGO，并与 Favicon 一起返回给 C 端。
- 删除基础配置中未使用的版本号配置，不影响独立的项目升级功能。
- 新增短信宝短信渠道，支持自定义签名、验证码内容、连接测试和测试短信发送。
- 短信验证码有效期、发送间隔和每日发送上限调整为后台可配置并由 Java 动态执行。
- 修复邮箱账号、发件人地址及同类文本编号字段被错误识别为数字输入框的问题。
- 完善短信宝验证码模板校验、响应解析和敏感日志保护。
- 统一后台用户身份判定并加固管理端上传失败处理。
- 修复平台品牌图片保存后未即时生效及清空页签图标后旧图标残留的问题。
- 邀请码改为发送登录验证码前预校验、首次注册时严格复核并自动绑定，删除独立预校验接口。
- 合并本次数据库更新为可重复执行的 `v1.0.0-beta.2.sql` 迁移脚本。

## v1.0.0-beta.1

- 发布 AID 首个公开 Beta 测试版本，面向自行部署和参与改进的开发者与创作者开放。
- 上线 AI 漫剧创作能力，覆盖创意、剧本、角色、场景、分镜、配音和成片流程。
- 上线 AI 电影项目化创作能力，支持叙事视频素材组织和生成任务编排。
- 上线 AI 漫画创作能力，支持角色、道具、场景、分镜和漫画画面统一管理。
- 建立图像、视频、语音和大语言模型的统一多模型接入能力。
- 建立生成任务统一调度、状态管理和计费处理链路。
- 上线用户、模型、供应商、系统配置、运营数据和版本升级管理后台。
- 提供初始化 SQL、Linux 部署脚本和 AID 升级器，支持项目部署与后续升级。
- 发布包含 608 个官方图片、音频试听和演示视频文件的配套资产包。
