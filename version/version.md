## v2.0.0（2026-09-05）

### 生成任务与错误提示

#### 修复与优化

- 提示词超长、内容审核失败及其他已识别的生成错误保留具体原因；同步提交、任务详情、任务列表和 SSE 重连使用同一错误快照。
- 批量分镜图片与视频任务保留每项失败原因；提交校验失败时也能查看对应分镜和生成次数，全部失败不会丢失明细。
- 修复对口型父任务查询遗漏执行周期导致误报停止的问题，已结束任务的迟到事件不再重复推进。

#### 数据库变更与升级注意事项

- 升级服务前执行 `sql/v2.0.0.sql`，为现有父任务和媒体任务新增可空错误快照字段；脚本兼容 MySQL 5.7、可重复执行，不修改历史任务和自定义规则。
- 历史任务没有快照时继续按原错误文本兼容识别；原始原因已丢失的历史记录无法恢复具体错误。现有接口字段保持兼容。

### 部署与站点网关

#### 新增与优化

- 升级管理新增 Nginx 网关配置，支持后端服务地址、上传大小、超时和安全指令白名单，兼容 Docker、原生部署及前后端分机部署。
- 配置应用前执行校验，按配置指纹防止并发覆盖，支持失败恢复、最近配置回退和任务中断后的恢复；仅操作当前安装的受管站点。
- robots 和 sitemap 根路径统一代理到配置的后端；不存在的静态页面返回 404，不再错误兜底到首页。
- 帮助页使用独立元信息，账户和创作页面默认不索引；静态发布校验全部必需页面文件，缺失或构建失败时禁止继续归档。
- 安装包携带受管模板，升级按持久化参数重新生成；运行配置使用目录挂载，避免容器看不到原子替换后的配置文件。

#### 数据库变更与升级注意事项

- 执行 `sql/v2.0.0.sql` 新增独立的 Nginx 管理权限；非超级管理员需明确授权。脚本可重复执行，不修改现有配置和角色。
- 需同步升级安装脚本、升级器、服务端、管理端与 Web。第三方自管 Nginx 不自动接管，按 `deploy/nginx/README.md` 手动接入站点资源与网关入口。
- 配置文件不接受任意 Nginx 文本或系统命令。修改域名和证书仍使用原有运行配置与证书管理入口。

### SEO 管理与搜索引擎抓取

#### 新增与优化

- 新增独立 SEO 管理中心，统一维护可索引页面、完整规范链接、页面标题、描述、关键词、站点地图和 robots 抓取规则。
- 新增百度普通收录 API 定时推送，每日 02:20 和 14:20 扫描待提交或内容已更新页面；推送失败仅记录脱敏日志并按退避策略重试，不影响内容发布状态。
- 管理员可批量复制未提交的完整链接、下载 `urls.txt`、打开百度手动提交入口，并可对手动提交结果进行确认；百度接口受理与搜索收录状态明确区分。
- 百度准入密钥仅支持更新或清空，使用部署密钥加密存储且不会由管理接口回传明文。
- 系统配置不再重复编辑 SEO 分类、网站描述和关键词，保留历史默认值，由独立 SEO 管理统一维护。
- 百度提交记录同时保留脱敏后的错误码和具体说明；配额耗尽安排次日重试，限流、超时及服务端异常按退避策略重试，配置类拒绝保留管理员处理入口。
- 百度提交时自动将完整站点地址转换为资源平台要求的主机名参数，修复包含协议时返回 `site init fail` 的问题；后台仍以完整地址校验页面同源关系。
- 历史记录若仅保存 HTTP 状态码，将明确提示原因不可还原，并在下一次定时任务中自动重新排队；更新后也可由管理员立即重试查看完整说明，不修改历史日志或内容发布状态。本次修复无需新增 SQL。

#### 数据库变更

- 升级执行 `sql/v2.0.0.sql`；新安装结构同步进入 `sql/aid-init.sql`。脚本兼容 MySQL 5.7、支持重复执行且不会覆盖已有 SEO 配置或密钥。

### Skill Runtime 与剧本能力

#### 新增功能

- 新增通用 Skill Runtime，提供入口目录、调用、动态澄清、运行详情与历史、可恢复事件分页、断线续传、运行取消及审计能力。
- 新增不可变 Skill 版本、资源摘要、固定子 Skill 关系，以及草稿、校验、发布和版本切换能力。
- 内置剧本入口调度、剧本写作和独立审核三个公共 Skill，支持新建、续写、改写、规范化、客观修复、项目或剧集上下文、历史运行和批注选段。
- Skill 版本按可用文本模型生成模型池；没有可用文本模型时保留完整初始化结构并保持停用，管理员完成模型配置后再启用，不阻断数据库升级。

#### 兼容性说明

- Skill Runtime 不改写现有智能体、风格与用户配置；内置子 Skill 只能由固定版本入口 Skill 调用。
- 数据库迁移不要求 `CREATE ROUTINE` 权限，兼容 MySQL 5.7。

### 供应商余额监控与通知

#### 新增功能

- 新增管理员显式选择的供应商余额监控、余额快照、告警事件、发送记录、理论成本台账与提醒人管理。
- 支持可维护的余额不足规则、分级阈值、连续确认、提醒间隔，以及邮件、短信和微信公众号组合提醒。
- 新增余额日报；查询失败或供应商不支持余额查询时给出不可统计状态，不以异常结果触发余额告警。

### 账号安全

#### 新增与优化

- 新增首次设置密码、密码修改、手机号或邮箱双验证码换绑、账号安全状态、在线会话管理、登录历史查询和账号注销后的再注册限制。
- 登录、设置、修改和找回密码统一使用公共密码长度规则；登录历史使用稳定用户 ID 关联。
- 注销限制仅保存不可逆身份摘要，已有安全配置和合法配置值在升级时保留。

### AI 模型与业务编排

#### 新增与优化

- 新增 AI 业务编排统一入口，并保留既有细粒度权限和兼容路由。
- 文本生成支持单次请求级流式、思考开关、思考档位和预算参数；文本消息支持图片、视频、音频与文档等结构化输入。
- 模型能力配置支持输入输出模态、数量与文件限制、上下文、输出上限和思考能力；只迁移可识别的官方模型基线，不重置其他模型或用户自定义能力。
- 清理模型与供应商配置中不应持久化的单次运行参数，并安全退役已明确下线且无活动引用的模型。

### 媒体任务与角色资产

#### 优化与修复

- 媒体任务新增不可变终态时间和 ETA 聚合基线，修复终态进度被旧事件覆盖及预计进度长期停留的问题。
- 角色和道具同一形态只保留一张主图；历史重复主图按稳定顺序收口，场景图片仍支持多选。
- 角色自动生图复用现有角色设定卡形态，仅调整可识别的系统元数据，不复制或覆盖用户维护的提示词正文。

### 管理后台与 Web 用户端

#### 优化与修复

- 系统配置隐藏供应商余额监控和任务等待时间的内部配置分类；余额设置统一在“供应商余额监控”页面维护，等待时间继续按现有统计规则自动计算。保留已有配置值，无需执行数据库脚本。
- Web 登录守卫统一收口到登录弹窗与安全返回路径，修复直接访问受保护页面时可能出现的跳转循环。
- Web 首页聚焦 AI 漫剧、AI 电影与 AI 漫画创作入口，不依赖运营 Banner 或内容发布接口；作品库保留项目管理、分集管理与本地导出能力。
- 修复全新环境依赖安装和静态资源地址不确定的问题；静态发布必须生成完整入口和 SPA 回退文件。

### 数据库变更

- 升级统一执行 `sql/v2.0.0.sql`；其中已按原开发脚本编号固化执行顺序，首次安装继续使用同步后的 `sql/aid-init.sql`。
- `sql/aid-init.sql` 已同步新安装基线；初始化数据只保留公共结构、51 条基础风格以及公共 Skill 数据。
- 增量脚本兼容 MySQL 5.7并支持重复执行；已有合法配置、密钥、倍率和用户自定义提示词不会被覆盖。
- 升级脚本仅撤销早期初始化中非当前公共基线的遗留菜单与配置；历史孤立表和用户业务数据保持原样，当前公共代码不再访问这些对象。

### 升级注意事项

- 升级前请先备份数据库，并确认执行账号具备建表、改表、索引和数据更新权限。
- Skill Runtime 初次升级后如未配置可用文本模型会保持停用；配置并验证文本模型后再由管理员启用。

## v1.0.2

### 修复内容

- 修复 Docker 在线源码构建完成三端编译后，因前端子目录无法访问统一仓库根目录 `.git` 而在生成发布包元数据时报错的问题；三端构建信息统一记录同一源码标签提交。
- 修复低内存服务器在线源码构建时 Maven/Javac 自动堆最低仅为 256MiB、编译大型模块可能触发 `OutOfMemoryError: Java heap space` 的问题；Maven 自动堆和实时准入下限统一提高到 512MiB，并同步提高物理内存硬限制基线。
- 修复 Linux 源码构建在非 UTF-8 系统环境中无法读取中文文件名、导致 Maven/Javac 报 `InvalidPathException` 的问题；Docker 与非 Docker 构建阶段统一使用 UTF-8 locale，并固定 Maven 的内容编码和文件系统编码。
- 调整在线源码构建的磁盘治理：磁盘空间不再复用 CPU 与内存的 15% 保留比例，只按可配置的绝对可用空间安全线执行准入和暂停，同时保留接近写满时的硬危险保护。
- 修复统一源码仓在网络抖动或标签检出不完整时误报 `frontend/admin/package.json` 缺失的问题；构建前会分别核验远端标签、实际提交、Git 文件树和本地工作区。
- Gitee 首次检出异常时先清理不完整目录并按精确标签引用在同一来源重试，连续校验失败后才切换 GitHub，避免国内网络环境因备用源不可达而直接中断。
- 发布工具在源码快照推送前和更新清单激活前校验统一仓的服务端构建文件、两个前端的依赖清单及源码构建器，缺少任一契约文件都会阻断发布。

### 升级说明

- 本版本不包含数据库结构或初始化数据变更，不需要执行额外 SQL。
- 源码检出失败发生在编译和版本切换之前，不会替换当前运行版本；修复网络后可安全重新执行安装或升级。

## v1.0.0

### 修复内容

- 修复 Vidu 图片与视频模型连通性检测使用非数字虚拟任务 ID 导致参数解析失败，以及遗漏解析 `reason=CreateFailedTaskNotFound` 结构化“任务不存在”响应而误报接口地址不存在的问题；正式生成与轮询流程保持不变。
- 可配置异步视频协议支持按模型能力映射或禁用上游音频开关字段，未配置时继续兼容 `generate_audio`；支持音画同步但由上游隐式处理的模型可继续向 Web 展示音频能力，同时仅下发 `referenceAudios`，避免误传 `audio` 或 `generate_audio`；提交失败日志同时记录业务模型码和真实上游模型码。
- 后台模型能力编辑支持为可配置异步视频协议选择 `generate_audio`、`audio` 或“不下发”三种音频传输方式，保存时保留并校验该配置，避免编辑模型后回退到不兼容的默认字段。
- 可配置异步视频协议支持按模型配置业务分辨率到上游参数值的映射，未配置映射时继续兼容原有 `2K` 到 `1440p` 的默认换算，避免不同渠道对同一档位采用不同参数值时提交失败。
- 后台模型能力编辑新增结构化上游分辨率映射，可按已配置的业务规格逐项填写上游参数值并写入能力配置，无需手工编辑 JSON；保存时校验映射档位与模型规格一致。
- 修复 Web 端缓存公开配置后重复按旧服务端时间计算加密请求时间戳的问题；现在会保存稳定时差，并在服务端返回“请求已过期”时合并刷新公开配置、重新加密且最多重试一次，避免页面长时间停留或服务器时间存在偏差时请求持续失败。

## v1.0.0-beta.7

### 新增功能

- 剧本列表、详情与保存响应新增正文内容哈希，保存和自动保存支持携带编辑基线进行并发校验，避免不同页面或设备静默覆盖。
- 剧本自动保存允许同步空正文并保持版本号不变，手动保存继续要求正文非空并创建新版本。
- 历史剧本删除改为仅允许软删除历史版本，当前使用版本和兼容草稿保持只读保护。
- C 端可用模型列表新增结构化最终费用明细：每个模型按 SKU 返回已完成全局倍率、模型倍率与现有扣费系数折算的价格、计费单位、公开命中条件及是否依赖任务完成后真实用量；同一模型存在多种计费口径时保持单模型展示，免费模型的列表价格与全部档位价格统一返回 0。
- 新增 `POST /api/user/billing/quote` 权威报价接口，直接复用正式任务的媒体计费准备、SKU 命中、预冻结计算及复杂业务只读计划，可报价图片、视频、文本、语音、素材提取、分镜脚本与提示词、分镜出片、编辑/高清/机位图、配音和对口型等付费操作；接口不创建任务、不冻结余额、不调用上游，也不下载远程素材。
- 报价结果返回命中 SKU、计费口径、单位、金额、预冻结金额、公开命中条件与确定/预估标记；按次、按张、按字符及请求参数已确定的按秒费用可展示确定金额，Token 或依赖任务完成后真实用量与退款结算的费用明确标记为预估。
- 图片模型选型支持仅按模型、生成模式、规格、比例、张数和预期参考图数量进行只读计价，不要求先填写提示词或上传参考图；模型选择、开始生图和素材提取入口可在提交前直接展示最终积分报价。
- `TASK_RESUME` 报价按任务实际未完成槽位逐项重建续跑费用，覆盖素材提取、分镜脚本、图片/视频提示词、分镜图片/视频和三类素材批量任务；仅接受当前用户项目内的可续跑任务，不重复计算已成功项。正式续跑与报价共用同一只读计划，图片/视频续跑须先取得全部目标锁再进入计费链路。
- 新增万相 `wan3.0-video-prime` 与 `wan3.0-video` 两个全模态视频模型；单一模型编码统一支持文生、首帧、首尾帧及图像/视频/音频参考，不按分辨率拆分模型，并按 480P、720P、1080P 独立 SKU 计费。
- Agnes 服务商新增 `agnes-video-2.5` 与 `agnes-video-2.5-flash` 两个异步视频模型，覆盖文生、首帧/尾帧和图片/音频/视频参考模式；标准版按 720P、960P、2K 输出秒数及超过 5 张的输入图片计费，Flash 固定 720P、最多 5 张参考图且禁止参考视频，按当前限时免费状态初始化。
- 新增可配置异步图片与视频任务协议，支持模型列表只读探测、JSON 视频提交、JSON 或 multipart 图片提交、统一状态轮询、多参考素材装配及同源鉴权产物安全持久化。
- 模型新增专属 LOGO 配置与后台上传预览；C 端模型列表优先返回模型 LOGO，未配置时回退所属服务商 LOGO。
