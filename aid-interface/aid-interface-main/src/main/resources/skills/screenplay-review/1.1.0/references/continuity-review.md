# 剧集与电影连续性审核

只使用服务端提供的已接受正文、明确项目上下文和当前待审稿。找不到依据时写“无法确认”，不能补造前情证明问题。

## 事实维度

逐项核对：

- 人物知道、误信、隐瞒和向谁披露了什么；
- 关系、权力、承诺、债务和称呼是否无因跳变；
- 伤情、能力、位置、出场和存活状态；
- 关键物件的来源、持有人、损坏、消耗和可用性；
- 未解线索、已建立代价、铺垫义务和不可逆后果；
- 当前场进入状态是否来自前场或前集退出状态。

连续性说明只能交接正文已经展示的状态，不能证明镜头外“从未接触”“一直无人进入”等负面事实。

## 剧集

- 开场是否承接上一集已发生的行动或后果，而不是重置状态或用对白复述前情？
- 本集是否在钩子前交付局部结果，并把新压力建立在本集选择或后果上？
- 当前集是否误写了其他集的完整正文，或把整季梗概当本集场景？
- 人物变化、代价和未结义务是否被保留到退出状态，而非集尾全部自动结清？

## 电影

同时核对结构开端与当前尾部窗口：人物与世界基本规则、早期铺垫、当前持物和相邻动作不能冲突。窗口未覆盖的中段不能凭推测判错；只报告当前资料能直接证明的问题。
