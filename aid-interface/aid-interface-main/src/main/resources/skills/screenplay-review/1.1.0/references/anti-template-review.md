# 去 AI 味与反模板审核

“像 AI”“不够电影感”“套路”都不是有效问题。必须定位重复机制及其对当前故事造成的损失。

## 诊断层次

至少引用两个位置，再判断是否存在：

1. 因果重复：连续靠巧合救场、陌生人送答案、反派自曝或突然获得新资源。
2. 策略重复：所有冲突都是质问、否认、提高音量，没有筹码和换策。
3. 表达重复：同构微表情、整齐等长台词、每句动作加心理翻译、泛化情绪词替代表演。
4. 收束重复：每场都用金句、总结或完整结论封口，代价在本轮立即结清。
5. 信息密度均匀：每一拍都同样重要、同样完整，没有留白、冲击和后果处理的疏密变化。
6. 人物可替换：遮住名字后，用词、关系策略和风险承受没有差别。

修订目标必须指向机制，例如“保留公开施压与证据事实，让揭示由主角有代价的策略触发”，而不是只要求换词或增加形容词。

## 防止误报

类型惯例、仪式重复、喜剧回环、人物口癖、创伤性重复动作和固定片头都可能是有意选择。第二次出现若改变意义、关系、信息或代价，就不能只凭表面相似判模板。不确定时标为 `NOTE | AESTHETIC`，不能触发自动修复。
