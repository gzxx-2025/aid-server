# 故事与剧本审核表

审核者必须引用正文回答，不按固定模板计分。

## 观看承诺与整体运动

- 主角当前追求、有效阻力、失败代价和本轮兑现能否从正文读出，而非只存在于用户说明？
- 升级是否改变信息、权力、关系、风险、资源、空间或时间，还是重复同一种争吵、羞辱、误会、救场或揭示？
- 主要结果由人物选择及其后果造成，还是由巧合、新资源、外部无条件宽恕或对手突然失语送达？
- 结尾是否让局部结果或余效落地？开放、静止、反讽和安静收束都可成立；不要求统一新增钩子。
- 核心代价是否在成功后自动复位，导致前面的赌注失效？

## 场景

对争取或冲突场检查：谁想让什么发生、反对方用什么筹码、策略怎样受阻并变化、哪项事实或行动改变方向、退出状态如何推动后文。对手只是不说话、停止行动或离场，不能自动算作转向。

氛围、仪式、蒙太奇、过渡和后果消化场不必硬套对抗，但必须改变知识、关系、压力、节奏或物理状态。大声不等于有变化，安静也不等于无戏。

## 行动与可拍性

- 关键内心是否通过行为、证据、空间、物件、关系动作、沉默或有意声音表达？
- 动作是否空间连贯并产生后果，还是堆微表情和抽象情绪？
- 关键物件是否有来源、持有人和状态变化？重要文字、声音和转场是否能被下游识别？
- 承担主要阻力、筹码或代价的人是否参与了转向与反应，还是在主角行动后突然成为被动道具？
- 解决方案是否使用已建立资源并仍穿过核心阻力，而非新增便利条件直接清除困境？

## 对白

- 每个主要说话者此刻想从对方取得什么？受阻后是否换策略？
- 台词是否回应上一动作并改变下一动作，还是轮流替作者解释剧情？
- 人物声音能否由地位、关系、词汇、句法、回避方式和风险承受区分，而非统一金句或口头禅？
- 动作已表达的意义是否又被台词、旁白或总结句重复翻译？

## 条件化检查

只有正文明确使用时才启用：

- 重大选择：行动前两边是否都可执行且有价值，新增代价是否可见？
- 可争议证据：结论是否超过证据与展示验证支持的范围？
- 精确时限：移动、操作、等待、说话和反应是否容得下，或正文是否说明压缩、换策、缩小目标或失败？
- 有限次数：每个单位是否以要求的可见完成状态计数？

普通决定、普通线索、定性紧迫和风格化时间不能被强行升级为这些机关。
