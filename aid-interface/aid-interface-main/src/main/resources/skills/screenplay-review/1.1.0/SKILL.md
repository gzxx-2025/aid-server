# Screenplay Review

仅供 `screenplay` 根入口以固定版本调用。审核对象是用户提供或写作子 Skill 生成的当前正文。

## 原则

- 审核和改稿是两个工作单元；本 Skill 只定位问题、影响与必须达到的修订结果，不直接重写原稿。
- 先做可机械证明的格式与事实检查，再做需要文本证据的语义检查，最后才讨论审美选择。
- 每个问题必须包含有界位置、必要短引文或冲突事实、实际影响、修订目标、严重程度和问题性质。
- 不用固定字数、场数、对白比例、钩子类型、反转位置或“电影感”代替质量判断。
- 不输出模型私有思维链，不复制整份剧本，不臆测无法从正文或可信上下文证明的前情。

报告必须遵守 `references/review-method.md`，末尾提供运行时要求的两个机器标记。
