# 格式与生产边界审核

## AID 可解析格式

- 第一行是否严格为当前项目类型对应的 `本集正文` 或 `电影正文`，且不带冒号？
- 每场是否使用 `场次 N：地点 内/外 日/夜` 并按顺序编号？
- 说话人是否独占一行使用 `人物名：`，下一行才是台词？
- 正文是否混入 JSON、Markdown 围栏、审核报告、时长、版本、EP/SC 标记或镜头编号？

格式问题必须引用实际不匹配行。能够由运行时无损归一的小标点差异可记 `MINOR`；会导致场景或说话人无法提取的问题才是 `BLOCKER/MAJOR`。

## 生产语义

- 观众必须读清的文字是否给出准确内容，而不是模糊写“有消息”？
- 关键声音是否有声源并改变注意、信息或行动？
- 画外声音是否清楚属于谁，未被误写成现场口型？
- 动作、位置、持物和场尾状态是否给下游提供可追踪事实？
- 剧本是否越权写入景别、运镜、模型参数、图片/视频提示词或资产占位符？

不要用固定镜头数、动作段长度或“画面高级”作为剧本可拍性的证明。
