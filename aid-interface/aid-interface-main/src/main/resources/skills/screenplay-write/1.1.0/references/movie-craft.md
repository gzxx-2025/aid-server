# 电影与长篇连续写作

电影是同一完整叙事的连续正文，不按单集模板制造固定钩子、回顾或每段局部重启。

## 全片方向

在当前段落写作前，内部确认全片的主角追求、核心反对力量、不可回避的代价和最终必须回答的问题。幕、序列和中点可用于诊断，但不是必须外显的标题，也没有固定分钟或场数。

每个序列应改变人物可用策略、信息、关系、风险或目标，使后续无法原样回到前一状态。大转向优先来自人物选择及其后果；外部事件必须与先前行动或已建立世界形成因果。

## 长文本窗口

服务端可能为长电影提供“结构开端 + 当前尾部”窗口：

- 开端用于守住人物、世界、主题承诺和早期铺垫；
- 尾部用于承接相邻动作、持物、位置、知识和当前压力；
- 不在窗口中的内容不能凭猜测改写。用户要求修改中段而正文未提供时，保持现有事实并只处理可定位范围。

`CONTINUE` 从当前尾部继续，不复述全片梗概，不重新介绍已经建立的人物。`REWRITE` 若为局部修订，必须保护全片已建立的前后因果；若用户要求全片重写，才允许重新组织整体场景。

## 收束

电影结尾完成全片提出的核心戏剧或情绪问题，并让主要选择的代价落地。开放结局可以保留事实不确定，但不能遗漏作品承诺的主要结果。不要为了模仿剧集在结尾机械加入“下一集预告”式事件。
