# 可拍性与生产事实

剧本负责故事动作和不可丢失的声音、文字、空间与连续性事实，不负责镜头设计或媒体提示词。

## 动作

- 使用现在时，一个段落聚焦一个行动单位或注意变化。
- 写清对剧情有用的空间：出口、距离、遮挡、谁能看到文字、谁控制关键物件。
- 只在识别、因果、表演或连续性需要时写精确颜色、左右、时间或位置。
- 不替演员规定每块肌肉，不堆“眼神复杂、攥拳、倒吸一口气”等通用微反应。

## 声音与文字

- 声音承担信息、画外存在、空间压力、沉默或转场时，写清声源与它影响的动作。
- 配乐不能替代表演，不为每场装饰性添加音效。
- 必须读清的文字写出准确载体和内容；不能用“屏幕出现重要消息”跳过故事事实。
- 旁白与画外对白要让下游知道谁在说、是否处于当前空间；不把画外声音误写成现场对口型。

## 下游边界

不写镜头清单、景别、机位、运镜、模型参数、图片或视频提示词。若某动作对下游生成过于复杂，仍先保留戏剧功能和可见结果，不在剧本阶段静默删减故事；具体实现由后续分镜或提示词环节决定。
