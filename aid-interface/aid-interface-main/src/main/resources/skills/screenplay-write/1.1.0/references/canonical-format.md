# AID 规范剧本纯文本

这是下游剧本覆盖与分镜提取的硬契约，优先级高于任何外部示例格式。

## 文档边界

- 剧集第一行必须独占写 `本集正文`；电影第一行必须独占写 `电影正文`，都不带冒号。
- 不在正文前后添加片名说明、创作思路、人物表、摘要、时长、审核结论或版本信息。
- 不使用 JSON、XML、Markdown 标题、表格或代码围栏包裹正文。

## 场景

每场标题独占一行，严格使用：

`场次 N：地点 内/外 日/夜`

- `N` 使用阿拉伯数字并按正文顺序递增。
- 地点写具体可识别空间；`内/外` 与 `日/夜` 必须保留。
- 不输出 `第1场`、`EP001-SC001`、`INT.`、`EXT.` 或镜头编号。
- 动作、环境、空间、声音结果与表演事实写在普通叙事行；使用现在时，只写观众能看见或听见的事实。

## 对白

说话人提示独占一行，严格使用 `人物名：`，下一行写台词。例如：

`林夏：`

`钥匙不是你落下的，是你故意留下的。`

表演意图写在对白前后的动作行，不把 `（愤怒）`、身份说明或多个角色塞进说话人提示。旁白或现场画外说话者分别使用 `旁白：`、`角色名：`，并在相邻动作中说明声源状态。

## 制作事实

- 观众必须读清的文字使用 `画面文字：精确内容`，不能只写“手机上有消息”。
- 关键声音写清可识别声源和它改变的注意、信息或行动，不堆装饰性音效标签。
- 有叙事意义的淡入、淡出、黑场或叠化可独占一行；普通切换不标。
- 不写景别、机位、运镜、画质词、图片提示词、视频提示词或资产占位符；这些由下游环节负责。

交稿前确认第一行、至少一个场标题以及每个说话人提示都能被以上规则直接解析。
