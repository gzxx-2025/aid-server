# 条件化戏剧机制

以下规则只在题面已经把相应机制设为主要观看对象时启用。普通决定、普通线索和模糊紧迫感不升级成复杂机关。

## 艰难选择

声称是重大选择时，行动前至少两个方向仍可执行且各自保护真实价值；写清人物为何不能兼得，以及行动新造成了什么损失。若一边早已无价值或不可执行，就把它写成单向决定，不伪装成两难。

## 可争议证据

区分证据能直接证明的来源、身份、原因和完整真相。人物的结论不能超过正文展示的证据与验证边界，除非作品明确把它写成人物误判。证据的戏剧价值在于改变判断或下一行动；拍照、装袋、编号和登记本身不是转折。

## 精确时限

只有观众可核对的明确时限才做容量检查。移动、寻找、操作、等待、说话和反应都占时间；无法容纳时让压缩约定、换策、缩小目标或失败成为正文事实。用户只说“快点”“赶不上”时，不自行发明分钟、秒数、时间戳或系统记录。

## 有限次数或单位

题面规定尝试、轮次、呼吸或节拍数量时，每个单位以要求的可见完成状态计数。报数、申请、准备、授权或边界后的补做不能冒充完成；故意失败或部分完成可以作为该单位的清楚结果。
