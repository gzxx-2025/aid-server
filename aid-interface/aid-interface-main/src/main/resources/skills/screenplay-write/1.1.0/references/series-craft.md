# 剧集写作与跨集连续性

剧集的写作单位是当前集，但每一集都继承已接受版本的进入状态，并产生可供下一集消费的退出状态。不能把多集正文混在同一个当前集产物里。

## 进入当前集

从服务端给出的可信上下文提取：

- 人物知道、误信和隐瞒什么；
- 关系、权力和承诺处于什么状态；
- 伤情、能力、服装、位置和存活状态；
- 关键道具由谁持有、是否损坏或已消耗；
- 哪些线索、代价、约定和铺垫尚未结清；
- 上一集最后正在发生的行动与情绪方向。

只把已接受剧本和用户明确事实当作依据。未接受草稿、审核建议和模型猜测都不是前情。上下文没有建立的历史不得补写成既成事实。

## 单集运动

- 开场用正在继续的行动、已落地的后果或当前必须处理的矛盾接住前情，不让人物互相复述上一集。
- 本集应有自己的当前目标、阻力、方向性变化和局部兑现；钩子不能吞掉整集回报。
- 连续多集不能总靠同一种羞辱、误会、自曝、巧合救场或同类反转推进。升级要改变至少一种真实状态。
- 人物弧不是每集都“成长一次”，而是在压力下表现选择、退缩、代价或策略变化，并在后集保留残余。
- 支线进入当前集必须改变主线压力、关系或后续义务，不能只为提醒观众它存在。

## 退出与交接

结束时确保正文能追踪：谁在哪里、正准备做什么、各自知道什么、谁持有什么、关系与风险怎样改变、哪项代价仍未结清。下一集悬念必须来自本集已经发生的选择或结果；安静余韵也可成立，不强制每集最后新增陌生事件。

续写时承接相邻尾部场景，不重置场号、关系、伤情、物件或人物知识。若可信上下文明确不足以支持用户要求的前情，只写当前可确定的行动，不虚构缺失历史来缝合。
