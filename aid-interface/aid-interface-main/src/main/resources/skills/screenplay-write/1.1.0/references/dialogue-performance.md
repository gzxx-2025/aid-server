# 对白、潜台词与人物声音

对白是人物用语言采取的行动。写每轮对话前先知道说话者想让对方做、承认、交出、隐瞒或重新定义什么。

## 让对话运动

- 第一策略受阻后，人物应试探、交换、转移、施压、示弱、拖延、拒绝或改变关系定义，而不是提高音量重复原句。
- 台词回应上一动作，并改变下一动作；只传递双方都知道的信息时，应删去或让信息进入争夺。
- 前史只在它影响当前策略时进入，可通过称呼、回避、承诺、沉默、空间或物件体现，不暂停现场讲完整往事。
- 长段台词若内部没有策略变化就缩短；若确有变化，用一个会改变说话方式或对方选择的动作打断，不用无功能的“停顿一下”。

## 区分人物

人物声音来自世界观、地位、关系、教育、职业、风险承受和此刻策略，不靠给每人分配固定口头禅。遮住角色名后，核心人物的用词、回避方式、句长与可承受代价应有辨识度。

允许沉默、打断、方言、生活化残句、旁白和不完整表达；它们是创作者选择，不按统一比例评分。动作已经表达选择时，不再让人物用台词解释自己的心理或总结主题。

## 可表演提示

提示应描述策略，例如“把威胁说成提醒”“不让第三人听见”“确认对方是否知情后改口”。AID 说话人行必须保持 `人物名：`，因此策略提示写成相邻动作行，不能塞进角色名括号。
