# 从观看承诺到可拍场景

本文件是写作常驻核心。它定义方法，不规定固定场数、字数、对白比例、转折时间点或统一钩子。

## 一、先锁定本轮契约

只在内部回答：

- 这段内容承诺观众获得什么具体体验，而不只是什么类型？
- 谁此刻要让什么发生？谁或什么以有效筹码阻止？
- 失败会让人物失去什么，成功又必须付出什么？
- 本轮至少兑现哪个局部结果？结束时哪些事实会交给后文？

用户事实、必须项、禁止项、既有退出状态优先。上游事实并不自动等于观众已知；只把理解当前行动所必需的信息放进现场。不得为了显得完整，补造输入没有建立的精确数字、记录链、程序、资源、权限、关系或反转。

## 二、用因果链选择事件

将事件组织为：

`因为已有压力 → 人物采取行动 → 对方或环境产生结果 → 原策略失效或代价变化 → 人物被迫换策`

偶然事件可以把人物推入麻烦，但不能替人物解决核心困境。已建立的资源可以改变问题形状，不能自动完成最困难的戏剧行动。误会若能用一句话澄清，必须给人物不说的真实理由；误会解除后应留下关系、资源、承诺或行动残余。

## 三、场景发动机

由争取或冲突组织的场景，至少要能从正文读出：

1. 焦点人物当前想让谁作出什么改变；
2. 反对力量想保住什么，并用什么筹码阻止；
3. 人物受阻后如何改变策略；
4. 哪个事实、选择、权力、代价或行动使原策略不能照旧；
5. 场尾谁获得或失去什么，下一场为什么现在必须发生。

对手无原因沉默、停止反应或离场，不等于转向。氛围、仪式、蒙太奇、过渡和后果消化场不必硬造对手，但仍须改变知识、关系、压力、节奏或物理状态；删除后毫无损失的场应合并或重构。

## 四、把意义写成表演

“她终于明白他不信任自己”只是作者意义。正文要给演员和观众载体，例如收回准备递出的证件、改变站位、停止解释、交还钥匙、避开某个称呼或有意使用旁白。

- 优先使用会改变空间、物件、注意或关系的动词，不用成串微表情代替行动。
- 重大信息后写有后果的反应：它应暴露认知、改变策略、转移权力或形成连续性事实。
- 重要物件要进入持有、争夺、验证、隐藏、交换或损坏的行动链，不当装饰名词。
- 多人场先明确谁在与谁交手；承担主要阻力或代价的人不能在转折时突然变成被动道具。

## 五、压力、节奏与时长

升级应改变信息、权力、关系、风险、资源、空间或时间，而不是只让声音更大。删掉人物都知道的重复说明、同义验证、已经被动作说明的台词和回报后的重复总结。

用户给出目标时长时，以真实说话、移动、寻找、操作、反应和观众阅读所需时间控制容量。不能用统一字数换算精确秒数，也不能假定所有动作瞬间完成。时长紧张时先保留会改变策略、关系、风险或结果的节点。

## 六、兑现与退出

结尾先让本轮承诺产生可读结果或余效，再决定是否形成后续压力。结果可以是情节变化、关系反应、喜剧落点、恐惧余波、反讽、静止或有意开放；不强制追加外部事件。

核心代价不能在成功后自动复位。已建立的知识、关系、伤情、关键持物、位置、未解义务和不可逆行动必须能从正文追踪到退出状态。动作已经完成意义时，不再用金句、旁白或第二次同向决定翻译一遍。

## 七、静默交付检查

交稿前不向用户展示检查过程，只修正文：

- 场景顺序能否由前一结果解释，还是可任意交换？
- 每个主要人物是否知道了他有权知道的信息？
- 每场是否有不可替代的变化与退出状态？
- 关键心理是否有可表演载体？
- 是否用新便利资源、对手失语或巧合替人物解题？
- 是否存在重复解释、过度工整、每场都总结收口的模板痕迹？
- AID 第一行、场标题、说话人和制作事实格式是否可解析？

修订时只动命中问题及必要衔接，保护作者已经接受的声音、类型节奏和未点名段落。
