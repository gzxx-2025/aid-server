# Dramaturgy craft

先把本段的观看承诺写成一句可验证的观众体验，再明确人物此刻想得到什么、谁或什么阻止他、失败会付出什么代价。事件应形成压力递增的因果链：前一行动改变局面，迫使人物作出下一选择，而不是并列罗列情节。

每场必须有不可替代的叙事功能、镜头可见的状态变化和清楚的 exit state。若删除一场不会改变人物选择、信息差、关系或风险，该场应合并或重构。只在题面已经建立备选项、证据或明确时限时使用选择、揭示或倒计时结构，不为套用结构凭空补造机关。

完成后静默反查观看承诺、因果跳步、人物知识边界、场景功能和连续性。局部修订只修改命中问题的场与必要前后衔接，保留无关段落。
