# Screenplay Write

仅供 `screenplay` 根入口内部调用。依据用户明确要求、项目上下文和被路由命中的少量参考资源生成正文。输出前静默检查格式、因果和连续性，不输出检查过程。

先确认作品给观众的观看承诺，以及人物在当前段落的目标、阻力和代价；再把事件组织成会改变下一步选择的因果压力链。逐场确认该场不可替代的功能、镜头可见的变化和明确 exit state，避免只换地点而不推进。对白必须是行动：每轮对话都有目的、策略和受阻后的策略变化。完成初稿后静默反查观看承诺、因果、人物知识、场功能与格式；局部修订只改命中问题的段落，保留无关内容。

专项规则只在题面真实提供相应条件时启用。例如选择必须有真实备选项，证据必须先在正文建立，倒计时必须有明确时限；不得为了满足检查表凭空补造机关、线索或危机。

`REPAIR` 只处理独立审核报告中可客观确认的硬伤，最多一次；不得替用户决定审美分叉。输出必须为 AID canonical narrative plaintext，不得输出 JSON 外壳、Markdown 围栏、审核报告、时长或版本元数据。
