# 版本说明

## 未发布

## v2.1.2（2026-09-12）

### 模型管理

- 批量绑定模型池弹窗新增业务能力与默认能力选择；唯一模型默认能力自动选中，无唯一默认值时提供行内校验并阻止误提交。
- 已删除模型不再显示为可绑定占位项；失效历史引用由服务端快照忽略并由升级脚本清理，停用但仍存在的模型继续保留和显示。

### 升级说明

- 后台管理端无需单独执行数据库脚本；请同步更新服务端，并由服务端执行可重复运行的 `sql/v2.1.2.sql`。

## v2.1.1（2026-09-12）

### 模型管理

- 能力编辑新增“对话前缀续写”开关，适配 DeepSeek 官方补全协议；加载、编辑与保存保持其他能力及扩展配置不变。

## v2.1.0（2026-09-12）

### 管理后台

- 模型编辑默认打开能力配置，分辨率、比例、时长、音画同步和参考媒体开关可直接编辑；完整能力控件继续保留。SKU 与价格提升为同级独立入口，按调用协议分别维护，避免在多层协议页签中查找。常用能力编辑仅更新对应字段，保留其他能力 JSON 与 SKU 顺序，无需数据库变更。

- 模型列表新增计费配置概览，直接展示固定价或 SKU 计费状态、启用 SKU 数量、官方原价摘要、价格缺口和单模型倍率，无需进入编辑弹窗即可核对计费完整性。
- 模型能力改用可见卡片切换并同步标明各能力的计费状态；固定价与 SKU 模式改为并列选择，SKU 编辑器增加启用数、已配价数量、单条 SKU 价格及命中条件摘要。保存继续保持 SKU 原顺序及未知计费 JSON 字段，不重建未修改配置。
- 本次仅优化后台计费配置展示与交互，无需新增服务端代码和数据库变更。

- 修复供应商余额有返回但不展示的问题：按币种余额、积分和资源包分别呈现总量及明细，保留零值和负值，显示查询时间、失败原因与明确空态。
- 上游任务默认显示全部状态，切换页签自动加载；兼容可灵与 MiniMax 状态、分页和查询范围，翻页失败保留原页，查询按账户与业务键合并并发请求。
- 余额监控显示官方单位并校验阈值单位，查询不可用不再显示正常，既有告警状态保留；查询失败时不再统一提示检查成功。无需数据库变更，需配套服务端余额响应修复。

- 优化 TokenDance 重新授权成功提示：移除官网嵌入页，改用清晰的旧 Key 清理说明与官网管理链接；授权及凭证保存逻辑保持不变。

- 模型编辑集中管理基本信息、能力与参数、调用配置、计费和业务绑定；嵌套字段、默认值、素材限制和条件规则全部使用表单控件，支持参数预览。
- 业务池绑定统一模型及所需能力；新增模型迁移预检与冲突选择，提供模板差异预览，保留已有合法自定义配置。
- 配置读取合并同请求键的进行中请求，保存期间阻止重复提交。部署本功能需配套模型能力服务端及数据库增量脚本。
- TokenDance 模型目录明确展示“不兼容 AID · 禁止导入”、原因及不可被目录刷新解除的提示，并支持按该状态筛选；批量选择和导入继续遵循服务端兼容门禁。

- 优化模型配置页的 TokenDance 推荐区域，使用本地品牌 Logo，清晰展示接入入口、账户能力和模型数量。
- 精简模型列表，移除能力、计费模式、模型接口路径、API 版本、图片类型、原价、并发和优先级展示列；模型 Logo 与名称合并展示，调整筛选、批量操作及窄屏布局。
- 本次仅调整后台页面展示，原有模型配置与接口保持兼容，无需数据库变更。
- 修复模型列表过长时无法纵向滚动的问题；TokenDance 目录支持切换每页 10、20、50、100 条，筛选与重新加载后返回首页，翻页和调整每页数量不重复请求目录接口。

### Skill 管理

- 修复 Skill 草稿只调整模型池且未打开 Schema 页签时，未挂载字段被误判为空的问题；历史空输入或输出 Schema 按合法空对象兼容，损坏的非空 JSON 仍会明确拒绝。
- 修复包含固定子 Skill 的草稿在放弃未保存修改并关闭编辑器时页面异常的问题。

### 案例广场

- 恢复案例广场审核与发布管理页面、路由和权限入口，支持查看发布快照、审核发布、驳回和下架。

### 升级说明

- 后台管理端不单独执行数据库脚本；从 `v2.0.1` 升级时需同步部署服务端、后台管理端和 Web，并由服务端执行 `sql/v2.1.0.sql`。
