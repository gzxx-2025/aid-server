# 版本说明

## 未发布

## v2.1.0（2026-09-12）

### 创作流程

- 编辑分镜视频的多参生成面板支持从本地和资产库导入参考视频；视频会登记为当前项目的分镜记录，并以可编辑的 `@视频N[名称]` 引用写入描述框，报价与生成请求按选择顺序提交参考视频记录 ID。模型能力、数量限制、素材条删除和文本引用删除保持双向一致，原有参考图与参考音频流程不变。

### 模型选择与生成参数

- 业务入口展示统一模型名称，参数选项使用当前业务能力；模型合并后可恢复旧模型编码和 ID 对应的选择，无法唯一匹配时不自动改选其他模型。
- 公共模型列表读取合并同请求键的进行中请求，重复打开或强制刷新仍复用正在执行的请求。

### 案例广场

- 恢复“发布至案例广场”的公共入口与交互，作品可以提交审核并查看发布状态。

### 充值与计费

- 修复充值中心关闭订单管理或消耗明细侧栏后透明遮罩残留、页面无法继续点击的问题；两个侧栏改为互斥状态并独立于主弹窗挂载，关闭时立即释放遮罩命中并在退场后销毁 Portal。

### 素材准备

- 角色、道具的形态编辑入口与主资产入口统一使用主图单选规则，覆盖生成记录、中间操作栏、导入确认、生成结果接管和重新打开后的状态恢复；场景继续支持多选，参考图多选不受影响。

### 我的作品

- 电影和剧集列表按服务端契约默认每页加载 20 条，滚动到底部自动加载下一页，并沿用统一的加载提示和卡片渐入效果；切换类型或搜索时隔离旧分页响应，避免结果串页。

### 首页与导航

- 修复登录弹窗、视频预览与编辑弹窗遮挡全局消息提示的问题，统一消息与通知的反馈层级。
- 首页主要导航预加载路由，并在首次跳转等待期间即时展示加载反馈；我的作品列表增加覆盖请求生命周期的全页加载状态。
- 流程页进入流程画布时增加导航中的即时反馈。

- 修复站点关键词或品牌图标未配置时，切换首页、我的作品和资产库触发页面卸载异常、导航失效的问题；站点标题、SEO 和图标统一由 React 管理。
- 未登记页面的 SEO 配置查询按正常空结果处理，保留页面默认信息。
- 移除左侧栏的开源和交流群入口及其浮层，保留教程、邀请和用户菜单。
- 移动端访问统一进入轻量提示页，并按开源站点视觉适配。
- 静态导出的 RSC 分段文件与客户端请求地址保持一致，避免纯静态部署访问页面时资源路径失配。

### 视频截帧

- 截帧弹窗按打开会话隔离视频与时间轴任务，关闭后再次打开重新初始化，旧任务不得覆盖新会话。
- 首尾帧选取与异步播放事件分离；解码失败不再回退到首帧，避免保存错误画面。
- 尾帧按微秒边界定位，不再以固定 30fps 偏移截取，兼容高帧率视频。

### 升级说明

- 本端不新增独立数据库结构；随服务端从 `v2.0.1` 升级时执行 `sql/v2.1.0.sql`，并同步更新服务端、后台管理端和 Web 静态资源。
- Web 静态资源更新后建议清理浏览器缓存或强制刷新；升级前仍应备份数据库、部署配置、证书和用户媒体目录。

## v2.0.1（2026-09-07）

### 创作流程

- 修复首页壳层重复切换后浮层挂载竞争、透明遮罩残留或导航失效的问题；登录、开源信息、交流群和用户菜单统一使用独立 Portal 容器。
- 修正登录弹窗背景显示，避免弹窗适配容器出现底色不一致。
- 素材准备中的场景、角色、道具列表为空时也支持手动添加，无需先自动提取；同步或添加期间保留操作保护，避免重复创建。
- 修复音画同步列表在高分辨率下视频区域和行内内容被裁切的问题；预览区域与视频生成列表共用自适应高度布局，保留长台词内部滚动及生成状态展示。
- 优化场景角色道具图、分镜图、分镜视频和音画同步编辑器的高分辨率适配；内部面板、预览、Tab 和下拉控件统一随可用视口调整，浏览器缩放后自动回落，避免重复放大。
- 恢复我的作品与创作流程顶部的流程画布入口，以及作品/剧集绑定、流程连线、节点编辑、右键菜单和视频导出；保留节点主图展示、输入面板跟随与空格平移保护。
